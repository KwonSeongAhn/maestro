# 신일 창문형 에어컨 — 냉기 유도 덕트 어댑터 (Square‑to‑Round)

실외 창틀에 고정한 신일 창문형 에어컨(예: SMA‑C7000HS급)의 **냉기토출구에 씌워**,
유연 덕트호스로 **실내에 냉기를 끌어오기 위한** 3D 프린트 부품입니다.
에어컨 본체(=소음원, 컴프레서)는 창밖에 두고, 시원한 바람만 관으로 실내에 들이는 구조입니다.

---

## 1. 스케치 해석

손 스케치의 숫자를 다음과 같이 해석했습니다.

| 스케치 표기 | 의미 | 값(mm) |
|---|---|---|
| `140` | 사각 흡입구 **가로** (에어컨 토출구 폭) | 140 |
| `80`  | 사각 흡입구 **세로** (토출구 깊이) | 80 |
| `40`  | 사각→원형 **전이부 높이** | 40 |
| `110` | 원형 **토출구 지름**(왼쪽 둥근 주둥이) → Ø110 유연 호스 연결 | 110 |

즉 부품은 **사각(140×80) → 원형(Ø110)으로 변하는 전이 덕트(Square‑to‑Round transition)** 입니다.
스케치에서 둥근 주둥이가 아래로 휘어 있는 것은 “냉기를 아래/실내 쪽으로 끌어온다”는
뜻으로 보고, **꺾임은 딱딱한 인쇄물 대신 유연 호스로 처리**하도록 설계했습니다.
(인쇄 난이도·서포트·기밀·성능 모두 유리)

```
        Ø110 원형 칼라 (호스 연결)   ← 유연 호스가 여기 끼워져 실내로 냉기 유도
          ┌────●────┐   ▲
          │  전이부  │   │ 40 mm
       ┌──┴─────────┴──┐ ▼
       │  140 × 80 사각 │   ← 에어컨 냉기토출구에 씌움
   ────┴───[플랜지]───┴────  ← 창틀/본체 고정 + 기밀 테이프
```

## 3. ⚠️ 인쇄 전 반드시 실측하세요

`140 × 80`은 스케치 기준 **가정값**입니다. **실제 냉기토출구를 자로 재서**
아래 중 한 곳에서 `가로/세로`를 맞춘 뒤 STL을 다시 만드세요. 흡입구가 토출구를
**살짝 헐렁하게 감싸도록**(각 변 +1~2 mm 여유) 하면 끼우기 쉽고 기밀 테이프로 마감하기 좋습니다.

- **가장 쉬움** — `cold_air_duct_viewer.html`을 브라우저로 열고 슬라이더로 `가로/세로/토출 Ø`를 조절 → **STL 다운로드**
- **정밀** — `cold_air_duct.scad`를 OpenSCAD로 열고 상단 파라미터(`inlet_w`, `inlet_d`, `outlet_dia` …) 수정 → `F6` → Export STL
- **CLI** — `generate_stl.py` 상단 상수(`INLET_W` 등) 수정 → `python3 generate_stl.py`

호스는 시중 **Ø100 / Ø110 알루미늄 플렉시블 덕트**에 맞춰 `outlet_dia`를 정하세요.

## 4. 인쇄 설정 (권장)

| 항목 | 값 | 비고 |
|---|---|---|
| 방향 | **플랜지(사각)를 바닥에** | 평평한 바닥 = 접착 양호 |
| 서포트 | **불필요** | 전이부 오버행 최대 ≈ 수직 기준 21° (안전) |
| 재료 | **PETG 권장** / PLA 가능 | 여름 창가 고온·결로 → PETG가 내열·내습 유리 |
| 벽(둘레) | **3줄 이상** (벽두께 2.4 mm) | 기밀·강성 |
| 채움 | 15 % | 구조상 벽이 대부분 |
| 레이어 | 0.2~0.28 mm | |
| 전체 크기 | 약 169 × 109 × 68 mm | 대부분의 프린터 베드에 적합 |

베드가 작으면 뷰어/‑SCAD에서 `flange`(플랜지 폭)를 줄이거나 0으로 설정하세요.

## 5. 조립·설치

1. **실측 후** 흡입구 치수를 맞춰 인쇄합니다.
2. 어댑터의 **사각 흡입구를 에어컨 냉기토출구에 씌웁니다.** 틈은 **문풍지/기밀(우레탄) 테이프**로 막아 냉기 누설을 줄입니다. 플랜지의 나사 구멍(Ø4.5×4)으로 본체·창틀 브래킷에 고정할 수 있습니다.
3. **Ø110 유연 알루미늄 덕트 호스**를 원형 칼라에 끼웁니다. 칼라 바깥의 **비드(돌기)** 가 이탈을 막고, 호스 밴드나 테이프로 조이면 확실합니다.
4. 호스를 **창틈으로 통과시켜 실내 원하는 방향**으로 향하게 합니다.
5. 에어컨 가동 → 컴프레서·소음은 밖, 냉기만 호스로 실내에 유입됩니다.

> **결로 주의:** 차가운 공기를 나르는 호스 표면에 물이 맺힐 수 있습니다.
> **보온(단열) 커버가 있는 플렉시블 덕트**를 쓰거나 호스에 단열 테이프를 감고,
> 창틀 쪽에 물받이/흡습 처리를 하면 물방울 낙하를 막을 수 있습니다.
> 또한 실외 흡입 특성상 실외가 매우 더우면 냉방 효율은 실내 설치 대비 낮아질 수 있어,
> 호스 길이는 짧게, 단열은 충분히 하는 것을 권장합니다.
