# 3D프린트 부품 살덧붙임(Wall Reinforcement) 규칙 — LBH-3DP

참조 기준: `cold_air_duct_fused.stl` (수밀 1바디 · 균일벽 ~2.6mm · 샤프엣지 필렛 · <1.5mm 구간 0.4%)

## 1. 목적
STL 생성 시 부울 연산·리페어 과정에서 발생하는 **깃털엣지(feather edge)·나이프엣지·홀 주변 얇은 벽**을
제거하여, 프린트 시 파손·언더익스트루전이 없는 **최소벽 확보 + 샤프엣지 필렛** 상태로 만든다.

## 2. 판정 기준 (진단)
- 측정: `trimesh.proximity.thickness(mesh, points, exterior=False, method='ray')` — 표면 다수점의 실벽두께.
- 지표: `p1`(1퍼센타일), `<1.5mm 비율(f15)`.
- **합격선**: f15 ≤ 약 1.5%, p1 ≥ 약 1.2mm (참조 duct는 f15 0.4%).
- **오검(제외 대상)**:
  1) **나사산 크레스트** — 나사 산봉우리는 원래 얇음(정상). 소켓/섬스크류 축 반경 내 얇은점은 보강 금지.
  2) **면취(챔퍼)·기능성 얇은 립** — p1 ≥ 1.5mm면 프린트 가능(PEEK), 보강 불필요.

## 3. 보강 방법 (구현: `reinforce2.py`)
**복셀 팽창 = 민코프스키 외측 오프셋** → 살 추가 + 샤프엣지 자동 라운딩(필렛). 참조 duct와 동일 성격.
1. `m.voxelized(pitch≈0.35).fill()` → 3D 불리언 매트릭스.
2. `scipy.ndimage.binary_dilation(mat, ball(delta/pitch))` — 외측 균일 팽창.
3. `skimage.measure.marching_cubes` 로 재메시 → 수밀 1바디.
4. **중심 정렬**로 원위치 보존(`mm.apply_translation(m.center - mm.center)`).
5. 팽창으로 줄어든 **기능 홀 재절삭** — 실계측 `fasteners.json` 위치·기능별
   (THROUGH=clearHole 관통 / TAP=tapDrill 블라인드), 섬스크류 소켓=P2.0 암나사.
- 기본 delta = **0.8mm** (벽 +1.6mm, 외형 +1.6mm). 얇을수록 delta↑.
- **나사부 포함 부품에는 전체 팽창 금지**(나사 골이 메워짐) → 나사 없는 베이스만/국부 보강.

## 4. 검증 & 채택 조건
- 채택: `is_watertight and body_count==1 and p1_after > p1_before and 재절삭홀수 == 기대치`.
- 미달 시 원본 유지(파괴적 변경 금지).

## 5. 적용 결과 (본 세트 62부품 스캔)
| 부품 | 형상 | 판정 | 조치 |
|---|---|---|---|
| P32 | 6mm 사각프레임+M5통공4 | 실제 얇은 엣지 (p1 0.43, f15 2.9%) | **보강 적용** → p1 1.40, f15 1.35%, 외형 6→7.7t |
| P30 | 8mm 판+섬스크류소켓3 | 얇은점 100% **나사산 크레스트**(정상) | 보강 제외 |
| P23 | 20mm 블록+챔퍼 | p1 1.67mm(챔퍼, 합격) | 보강 불필요 |
| 그 외 59 | — | f15 낮음 | 정상 |

**결론**: 62부품 전량 수밀·1바디. 실제 살덧붙임 필요 부품은 P32 1종뿐이며 적용 완료.
